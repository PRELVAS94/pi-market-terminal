# Changelog

## 0.8.1 — Initial public package

- Four-pane quote, publisher-news, BLS-calendar and live-TV workspace.
- Watchlist editing, search, ticker tape, gainers/losers sorting and keyboard help.
- On-demand daily-close charts and public article/Key Points reader.
- Configurable polling, source health, timestamps and failure backoff.
- Local Kitty video up to 1080p with mpv audio and private IPC controls.
- Normalize macOS mpv shared-memory names so Kitty accepts the video frames.
- Native Kitty receiver regression test, portable preview and player fallbacks.
- Package/gallery metadata, user screenshot, MIT license and contributor docs.
